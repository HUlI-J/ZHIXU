# 知序 0.2.20

本版本在 0.2.19 的基础上完成整体界面质感升级，并固化了正式发布流程。

## 界面升级

- 全新 `premium.css` 视觉层：冷中性色底、深靛蓝强调色、分层柔光阴影与精细排版。
- 侧边栏加入选中指示条与项目圆点柔光；顶栏采用毛玻璃效果，层级更清晰。
- 按钮、卡片、输入框、对话气泡与弹窗统一升级，新增悬浮抬升与聚焦光晕反馈。
- 深色主题同步调校，文字对比度充足；支持系统「减少动态效果」偏好。
- 覆盖「今天 / 对话 / 项目 / 收件箱 / 报告」等主要视图，明暗两套主题均已验证。

## 发布与更新

- 继承 0.2.19 的正式发布流程修复：仓库所有者拼写统一为 `HUlI-J`，发布脚本支持 UTF-8、上传重试与资源三重校验。
- 新增 GitHub Actions 发布流水线与《发布与自动更新运维手册》，避免 Release 再次停留在草稿状态。
- 自动更新以 GitHub 正式 Release 为准；本版本发布后，桌面端会在检查更新时发现并后台下载。

## 数据说明

- 工作数据、附件、模型密钥和网页访问配置仍保存在用户本机，不随 Release 上传。
- 升级时沿用原有数据位置与安装位置，数据库文件仍为 `workbench.sqlite`。
