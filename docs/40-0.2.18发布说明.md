# 知序 0.2.18

新增内置免费 AI 体验与免费 API Key 获取向导：没有配置任何 API Key 的用户也能先把知序用起来。

## 内置免费 AI（体验版）

- 未配置自有 API Key 时，可使用内置免费 AI 完成对话、事项解析、润色与文档分析。
- 首次使用会弹出隐私说明，需明确同意后才启用；可随时在“设置 → 模型”关闭或改用自有 Key。
- 内置模式经知序的 Cloudflare Worker 免费中转访问国内免费模型；按匿名设备标识与 IP 每日限流，额度用尽后自动回退本地规则。
- 上游模型 API Key 只保存在中转服务端，客户端仅持有不含密钥的匿名设备标识。
- 中转服务源码位于 `worker/`，可用 `npx wrangler deploy` 自行部署，并在设置中填入服务地址；本地可用 `node worker/dev-server.mjs` 调试。

## 免费 API Key 获取向导

- “设置 → 模型 → 内置免费 AI”提供「获取免费 API Key」入口。
- 内置智谱 GLM、阿里云百炼、硅基流动、DeepSeek、Moonshot/Kimi 的注册与密钥链接、免费额度说明及分步指引。
- 粘贴 Key 后真实测试通过即保存为自有供应商；之后优先使用自有 Key，内容直连厂商，不再经过知序中转。

## 稳定性与降级

- 内置或中转不可用时，对话、润色、事项解析、文档分析均自动回退本地规则，原消息与内容不丢失。
- 外链仅允许打开白名单内的厂商官网与仓库地址。

## 数据说明

- 本地项目、任务、聊天记录、附件仍保存在本机。
- 使用自有 Key 时，供应商密钥保存在本机加密设置中；仓库不包含任何密钥或用户数据。
