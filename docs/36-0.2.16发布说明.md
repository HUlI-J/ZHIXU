# 知序 0.2.16

修复网页访问密码无法登录的问题，并把“数据与隐私”改为可选择工作数据保存位置。

## 网页访问

- 开启网页访问时，密码框留空会自动生成 36 位十六进制强密码，立即显示在窗口中并尝试复制到剪贴板。
- 修复此前“生成了密码但未真正保存或应用”造成的登录失败：访问已运行时点击“生成密码”，会立即保存新密码、关闭旧入口并重新开启，旧密码和原登录会话随即失效。
- 密码仍只保存加盐哈希，关闭窗口后无法再次查看；忘记密码时用“生成密码”重置并复制，不要继续使用截图中的旧密码。
- 开启和关闭按钮会随访问状态切换，状态轮询不再覆盖正在显示的生成结果。

## 数据与隐私

- “设置 → 关于 → 数据与隐私”现在说明：工作数据默认保存在本机 `%APPDATA%\Xiaoyu\`，不会上传到 GitHub，也可以自行选择其他本机文件夹。
- 新增当前数据路径显示、“打开文件夹”和“更改位置”。选择的新位置必须是空文件夹，不能与当前数据文件夹重叠。
- 更改位置会先保存当前工作、停止网页访问，再复制数据库、附件、插件、网页访问配置、备份和更新设置，校验数据库后自动重启知序。
- 原位置保留完整副本，不会在迁移成功后被删除。复制失败会清理目标文件夹，原数据不受影响。
- 启动时如果已选择的数据位置不可用，知序会回退到默认位置启动并提示原因，不会清空或覆盖原数据。
- 使用测试专用数据目录（`XIAOYU_DATA_DIR`）时不开放应用内更改位置，避免误改日常数据。

## 升级

覆盖安装即可，沿用原安装位置、桌面“知序”快捷方式和现有工作数据。网页访问密码在升级后保持不变；如需重置，在“网页访问”窗口点击“生成密码”。保存位置在升级时不动，只有主动点击“更改位置”才会迁移。
