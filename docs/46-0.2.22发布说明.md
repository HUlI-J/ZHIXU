# 知序 0.2.22

本版本整合了对话、报告、回顾和侧栏的交互与排版改进。

## 对话

- 长消息输入框向上扩展，达到高度上限后自动跟随光标。
- 模型生成时，发送按钮原位切换成蓝色圆形停止按钮。点击后中止当前请求，并在原提问旁标记“已停止”。
- 鼠标移到消息上，时间旁显示复制图标。自己的消息也可编辑后重新发送，原消息继续保留。
- 描述接手的新项目时，可以填写或修改名称并确认创建。成功后在原卡片标记“已创建”，保持对话阅读位置。

## 界面与布局

- 侧栏导航和工作台保持可见，项目列表可独立滚动。项目状态小点用绿色、黄色和红色区分正常、需关注和风险。
- 统一界面字体，修正回顾统计数字的显示。报告模板与正文顶部对齐，窄窗口的宽表格可在表格区域内滚动。
- 改善窄窗口下的顶栏、项目详情及长文本换行，调整深色控件和报告打印样式。

## 安装

Windows 用户可下载安装包 `Zhixu-0.2.22-Windows-Setup.exe`，也可在桌面端检查更新。本次发布提供源码压缩包和 SHA-256 校验清单。
