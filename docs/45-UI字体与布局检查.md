# UI 字体与布局检查（2026-11-18）

本次修改针对实际工作台源码，覆盖今天、对话、收件箱、项目卡片与详情、报告、回顾、连接与数据及常用设置和录入弹窗。未改变业务数据、报表计算或日期分段规则。

## 问题、影响及修复

| 问题与位置 | 影响范围 | 修复 |
| --- | --- | --- |
| `prototype/premium.css` 的 `--font-head` 指向 Songti/STSong/Noto Serif/Georgia | 全站标题、品牌及含日期的标题；不同系统回退为不同衬线字体 | 标题与正文共用系统无衬线字体，明确中文回退；标题 700，次级标题与模板 600，当前模板 700 |
| 三层 CSS 残留 8–10px 字号和 550/640/650 等字重 | 徽标、侧栏、聊天提示、表头、元数据、窄屏控件与弹窗 | 字号下限 11px，正文 14px，常规字重使用百位档；报告正文行高 1.8，标题行高 1.4–1.5 |
| refinements 的全局 `letter-spacing:0 !important` | 覆盖所有组件的字距设置，导致主题规则失效 | 改为 body 默认字距，保留局部组件控制 |
| premium 最后加载，覆盖侧栏宽度、搜索框最小宽度和窄屏边距 | 390/320px 下多数页面横向溢出，顶栏按钮越界 | 在主题末尾恢复 1120/920/680px 响应规则，搜索框允许收缩 |
| 报告工具栏嵌在右侧正文列，select 默认占满一行 | 左侧日报等模板和右侧纸张顶部不齐 | 工具栏移至两列共同上方，模板与纸张放在同一网格行；桌面正文左右内边距 30px |
| 报告表格无长文本与窄屏策略 | 英文长串撑宽、窄屏文字逐字挤压 | 长文本允许换行；表格最小宽度 520px，使用可聚焦的局部横向滚动区域；移动模板为两列 |
| 项目详情操作组与面板标题禁止换行 | 390px 详情页操作组溢出，320px 任务栏按钮越界 | 详情头部、按钮组和窄屏面板标题自动换行 |
| 插件样式使用不存在的 `--muted`/`--panel` 及固定浅色提示底 | 次要文字继承错误，深色模式提示不协调 | 改用现有 `--ink-2`/`--surface` 和语义色变量；改善主题次要文字对比度 |
| 深色主题未声明原生控件配色；主题覆盖打印样式 | 日期/选择框配色不一致，深色报告打印有底色 | 设置明确的 color-scheme；打印时使用浅底深字、去除纸张阴影和外框 |
| 代码、终端、插件 JSON 的中文等宽回退不统一 | 中文字形随组件改变 | 统一 `--font-mono`，保留代码等宽及中文回退 |

远程登录页的字体回退、输入文字颜色和旧浏览器 vh 回退也已统一；未进行公网登录或修改远程访问配置。

## 复测方法

```powershell
npm run test:ui-layout
npm test
npm run build
```

`test:ui-layout` 默认使用本机 Microsoft Edge 和隔离浏览器数据，检查 1440、1000、768、390、320px 的浅深主题，遍历七个主页面、六种报告、数据子页、项目详情标签、设置标签及录入弹窗；另验证长中文/无空格英文、报告顶部对齐、字重、缺失图片、运行错误和深色打印。测试通过 CDP 读取实际提供中文字形的安装字体，避免只检查声明的 font-family。

设置 `ZHIXU_UI_DESKTOP=1` 可检查 Electron 构建；设置 `ZHIXU_TEST_EXE` 指向安装版可复测安装产物。所有 Electron 测试数据写入证据目录内独立子目录，不使用正式数据库。设置 `ZHIXU_UI_EVIDENCE` 指定截图和 result.json 的保存目录。

本机证据保存在项目根目录 `logs/ui-audit/`，包括初始扫描、浏览器/桌面复测、构建日志和 136 项功能测试日志。仅在 Windows 的现有 Chromium/Electron 环境中运行验证；macOS、Linux、Safari、Firefox 和真实远程移动设备尚未实机验证。系统字体通过本机字体回退使用，无外网字体下载依赖。
