# 知序 0.2.17

统一知序 / Zhixu 品牌和默认数据路径，并交付此前的对话记录及项目有效性修复。

## 命名与路径

- 产品需求文档、信息架构、视觉规范、设计方案、设置页和预览入口统一使用知序。
- 新安装使用 `Zhixu.exe`，默认安装目录为 `%LOCALAPPDATA%\Programs\Zhixu`；旧版安装沿用原位置和“知序”快捷方式。
- 默认数据目录为 `%APPDATA%\Zhixu`。旧版默认目录会先通过 SQLite 备份并复制附件、插件、网页配置、更新设置和备份，校验成功后启用新目录，原目录保留。
- 已有自定义数据位置继续沿用；迁移失败继续使用原位置，已有的新目录不会被覆盖。
- 页面使用 `zhixuDesktop`，测试使用 `ZHIXU_DATA_DIR`。旧桥接 `xiaoyuDesktop`、旧环境变量 `XIAOYU_DATA_DIR` 和安装标识 `cn.xiaoyu.workbench` 仅作兼容保留，避免产生第二套安装记录。
- 设置中的仓库、问题反馈、自动更新与发布脚本统一指向 `HULI-J/ZHIXU`。

## 对话与项目

- 新消息保存日期时间并显示完整时间。
- 项目删除后清理相关对话、操作卡片及摘要缓存，失效路由不再展示其他项目详情。
- 未明确新建项目时拦截模型的创建动作。关联任务保留为未归属记录。

## 数据说明

本次修改不要求用户重置数据库，不会把用户工作数据、附件或密钥上传 GitHub。新旧数据目录的实际使用位置以“设置 → 关于 → 数据与隐私”为准。
