# 知序 0.2.21

本版本将界面统一升级为「墨青」视觉风格，整体质感与可读性进一步提升。

## 视觉风格：墨青

- 宣纸暖白为底，青瓷绿为墨与印，朱砂红只用于「逾期 / 待确认」等语义提示，不再作为品牌色。
- 青瓷色阶扩展为深 / 主 / 浅三级，标题、浅底、强调各有其位，层次更立体。
- 标题改用宋体并调整字距，正文行高放大，中文阅读更舒适耐看。
- 叠一层极淡宣纸纹理，卡片改为轻阴影与细描边，去掉生硬厚重感。
- 品牌标识统一为青瓷方印「序」，与整体色调一致。
- 深浅两套主题同步调校：「墨青」与「墨夜」，对比度充足。

## 覆盖范围

- 侧边栏、顶栏、按钮、卡片、表单、标签、对话气泡、输入区、弹窗与滚动条全面更新。
- 待办、逾期提醒、待确认草稿等状态在两套主题下均清晰可辨。

## 数据与更新

- 工作数据、附件、模型密钥和网页访问配置仍保存在本机，不随 Release 上传。
- 自动更新以 GitHub 正式 Release 为准；本版本发布后桌面端会正常收到更新推送。
