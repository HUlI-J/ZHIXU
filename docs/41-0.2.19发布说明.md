# 知序 0.2.19

本版本继承 0.2.18 的内置免费 AI 体验和免费 API Key 获取向导，并完成正式发布流程修复。

## 功能与修复

- 保留内置免费 AI 体验、首次隐私确认、免费 API Key 获取向导和本地规则降级。
- 自动更新以 GitHub 正式 Release 为准，不读取 `main` 分支提交。
- 发布脚本在创建、上传和发布前核验当前 GitHub 账号必须为 `HULI-J`。
- `main` 受保护，版本修改通过 Pull Request 审核合并后再创建 Release。
- 桌面回归测试兼容首次启动的内置 AI 隐私弹窗，并提高截图等待上限。

## 发布内容

- Windows NSIS 安装包、`.blockmap`、`latest.yml`、源码包和 SHA-256 清单。
- 工作数据、附件、模型密钥和网页访问配置仍保存在用户本机，不随 Release 上传。
