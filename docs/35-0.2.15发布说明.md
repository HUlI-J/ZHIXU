# 知序 0.2.15

修复公开版本的更新发现与提醒流程。

## 原因

- 0.2.13 及更早安装包的更新逻辑仍依赖 GitHub 凭据，公开仓库用户会看到“私有仓库”提示，无法自行发现修复版本。
- `v0.2.14` 的修复曾只上传到草稿。2026 年 11 月 2 日通过 GitHub 公开接口核实，最新正式版仍为 `v0.2.13`，公开下载用户尚未获得修复。
- 自动更新此前只自动检查和下载，下载完仅显示右下角入口，不会主动弹出更新窗口；安装需要手动确认。

## 变更

- 更新源固定为公开 GitHub Releases 匿名访问，移除更新令牌输入、存储、解密及错误恢复流程。
- 忽略并清理旧版本保存的更新令牌，不影响其他加密设置。
- 新版本下载完成后自动弹出更新窗口；其他窗口打开时等待其关闭，并保留右下角提醒。
- 用户重新开启自动检查后立即检查一次，不必等到下个六小时周期。
- 重启安装仍由用户确认；安装前继续保存工作并备份数据库，不会强制中断工作。
- 每个 Windows 用户的数据仍保存在各自本机 `%APPDATA%\Xiaoyu\`，GitHub 发布不包含个人项目数据。
- 侧栏工作台卡片移到底部，项目列表独立滚动，底部入口始终可见。
- 设置新增“版本与更新”和“关于”两个模块：更新状态、自动检查开关、检查与重启操作集中展示；关于页显示版本、GitHub 仓库、问题反馈和本机数据说明。
- 自动检查开关修改后立即保存，不需要再点“保存”；关于页外链只允许打开 ZHIXU 的 GitHub 地址。

## 旧版升级

0.2.13 及更早版本检查失败时，首次升级需从 GitHub Releases 手动下载完整安装包并覆盖安装；无需卸载、另建桌面入口或清空工作数据。此后安装版本即可匿名检查并自动下载公开新版本。

## 验证

- `npm test`：120 项通过。
- `npm run build`：类型检查与 Electron 生产构建通过。
- `npm run test:updates`：开发构建与打包版均通过；覆盖匿名更新配置、下载完成弹窗、其他对话框关闭后的延迟提醒、校验失败拦截及下载超时重试。
- Windows 安装包已生成于 `release/Zhixu-0.2.15-Windows-Setup.exe`；`latest.yml` 中版本、大小和 SHA-512 与本地打包结果一致。
- 发布后通过匿名接口核验 `latest.yml`、安装包和校验文件；0.2.13 及更早客户端无法通过旧更新流程获取本修复版，仍需手动覆盖安装一次。
